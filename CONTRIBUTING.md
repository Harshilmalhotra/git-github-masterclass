# Contributing to the Masterclass Repository

This repository is primarily teaching material.

## For students

If you are making changes as part of an exercise:

1. Create a branch.
2. Make your change.
3. Commit with a meaningful message.
4. Push your branch.
5. Open a Pull Request.
6. Request a review.

## Commit message examples

Good:

```text
Add branch exercise
Fix GitHub remote explanation
Update merge conflict example
```

Avoid:

```text
update
changes
test
final final
```

## Important

Do not modify course instructions during a student exercise unless the instructor asks you to.
