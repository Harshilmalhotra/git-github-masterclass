# Exercise — Your First Repository

Complete this without looking at the previous section once you start.

## Task

Create a local repository called `student-git-profile`.

It must contain:

```text
student-git-profile/
├── README.md
└── profile.txt
```

`profile.txt` should contain:

- Your name
- Your department
- One technology you want to learn
- One project idea

Create at least **two commits**.

### Rules

- Use meaningful commit messages.
- Check `git status` before and after commits.
- Use `git log --oneline` to verify your history.

### Success criteria

```text
[ ] Repository initialized
[ ] Two files created
[ ] At least two commits
[ ] Meaningful commit messages
[ ] Clean working tree at the end
```
