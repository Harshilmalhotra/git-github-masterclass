# Git Playground

This is your safe practice area.

The best way to learn Git is to experiment.

## Things to try

### Status

```bash
git status
```

### History

```bash
git log --oneline
```

### Diff

Change a file, then:

```bash
git diff
```

### Branches

```bash
git switch -c experiment
git switch main
```

### Inspect remotes

```bash
git remote -v
```

## Challenge

Try to answer these without looking them up:

1. What is the difference between `git add` and `git commit`?
2. Where does a commit exist before `git push`?
3. What is the difference between `git clone` and `git pull`?
4. Why do we use branches?
5. What does a Pull Request do?

If you can explain these in your own words, you're making good progress.
